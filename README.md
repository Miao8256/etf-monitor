# 宽基 ETF 手机实时监测网页

这是一个可部署到 Render 的 Python 网页服务。部署后会获得一个手机可访问的 HTTPS 地址；**本文件不是已部署的网址**。

## 部署到 Render

1. 将本文件夹的 `index.html`、`server.py`、`requirements.txt`、`render.yaml` 上传到你自己的 GitHub 仓库根目录（或把本文件夹作为仓库根目录）。
2. 登录 Render，选择 **New → Blueprint**，连接该仓库，按 `render.yaml` 创建 Web Service。
3. 等待部署成功，打开 Render 给出的 `https://...onrender.com` 地址，手机 Safari/微信浏览器均可访问。
4. Render 免费服务可能休眠，首次打开可能较慢。数据来自非官方公开接口，可能出现限流、无法访问或延迟。

## 近20日同分钟均值

服务端通过 `ndays=5` 尝试获取最近最多5个交易日的分钟记录；网页会将成功获取的完整交易日样本保存到**当前浏览器的 localStorage**，逐日累积到最多20个交易日。新设备、清理浏览器数据、或不足20日时不显示“真实20日均值”，会标注已有天数。不同设备的历史不会自动同步。历史不足时仍可对比上一交易日。

注意：20日均值指20个交易日**同分钟累计成交额**的平均，不是随意估算。缺失ETF/缺失分钟的数据日不会纳入完整样本。

## 注意事项

- 监测的是ETF二级市场成交额，不能当作国家队净买入或ETF净申购。
- 没有账户身份数据，不能确认“国家队买了多少亿”。
- 服务仅在接口可用时刷新，不会补造数据。
- 未接入商业行情授权，刷新约60秒，不保证交易所级实时性。
