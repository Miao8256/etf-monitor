宽基ETF盘中监测台

1. 电脑安装 Python 3（无需安装额外 Python 库）。
2. 将此压缩包解压，进入 etf_monitor 文件夹。
3. Windows：在文件夹地址栏输入 cmd 回车，然后运行 python server.py
   macOS：在终端进入文件夹，运行 python3 server.py
4. 用浏览器打开 http://localhost:8765
5. 每60秒自动刷新；停止服务按 Ctrl+C。

本程序从本地 Python 服务代理请求东方财富公开行情接口。接口可能更改、限流或拒绝访问；失败时显示错误，不生成虚假数据。
首次打开需联网加载 Chart.js 图表库。

特别提醒：成交额不是净申购额，更不能等同国家队买入额；图中异常放量只是研究信号。
